August 12, 2026 · ~90 min · one continuous case, built by you
01 · The Context

Beyond the Menu: Building a Restaurant Brand from Zero

Where You Start

You've spent years around kitchens and dining rooms. You know food, hospitality, and what makes a place worth visiting.

What's Missing

What you don't have yet is the business behind it — no financial model, no brand, no pitch. Normally that takes weeks and several people to build.

What Changes Today

Today, you build all of it yourself, in one sitting — with Claude as your team, end to end.

02 · What We're Doing

One story, three tools.

Chat → Cowork → Code — the same project carried through by CLAUDE.md and memory, so nothing gets re-explained at the handoff.

03 · The Output

Five deliverables, one consistent story.

Claude Project
CLAUDE.md, market research, and every file organized in one folder Claude reads automatically.
/project + CLAUDE.md
Financial Plan
Startup costs, operating costs, revenue assumptions, and break-even — assumptions stated explicitly.
.xlsx
Branding Guidelines
A locked visual direction, researched and validated before any artwork exists.
.md + skill
Investor Pitch Deck
6-8 slides, numbers pulled straight from the financial plan.
.pptx or .html
Landing Page
A working one-page site to capture the waitlist — built next, in Claude Code.

Prerequisites

  • Claude desktop app installed and signed in with your workshop account (claude.com/download)
  • Cowork mode enabled in the app
  • Claude for Chrome extension installed
  • Claude for Excel & PowerPoint extension installed
  • An empty folder on your computer to use as your project workspace
Pro tip: Cowork will ask for permission before it reads or writes files outside the folder you point it to, before running shell commands, and before installing anything new. Approve each action, or tell it to do something different — you stay in control the whole time.

Core Steps

1
Set Up Your Workspace
What you'll learn: configuring Cowork, connecting your tools, and creating your first skill.
▾

Before touching the case, get Cowork ready:

  • Open Cowork's general settings — enable memory, and set tool access to "load tools when needed"
  • Connect the connectors you'll want later (Gmail at minimum)
  • Confirm the Claude for Chrome and Claude for Excel/PowerPoint extensions are installed
  • Create a write-like-me skill so anything Cowork drafts for you later sounds like you
Look at my last 20-30 sent emails and create a skill that captures my writing style — tone, sentence length, phrases I use and avoid — so future drafts sound like me.
2
Discover the Opportunity (Claude Chat)
What you'll learn: opening a case with one simple question and letting Claude pull live web data.
▾
Chat

This part happens in a regular Claude.ai chat — no files yet. Start broad: no predefined cuisine, neighborhood, or angle going in.

I want to open a restaurant in NYC, but I'm not sure about what cusine, type, neighborhood and so on. Help me elaborate on this ideia. Remember to pull live data from the web so we are up to date with our research
3
Sharpen the Idea with grill-me
What you'll learn: using the grill-me skill to pressure-test an idea until it's a clear decision.
▾
Chat
  • Install the grill-me skill (in the folder downloaded)
OK. We need to refine the concept now. Please grill me on this ideia so we come to a clear vision for the restaurant
Tip: if the grill-me session is deviating too much from what you want to do, just steer it. Ask Claude to stop once you feel you've come to an understanding, then consolidate the decisions in CLAUDE.md and memory.
4
Deep Research (Optional)
What you'll learn: when it's worth pausing to gather more data points before locking the concept.
▾
Chat

Optional — if you want more data points before moving on, run a deeper research pass now, while you're still in Chat and before the concept gets locked into a project.

5
Move from Chat to Cowork
What you'll learn: turning a locked concept into a Cowork project, with CLAUDE.md doing the work Instructions usually would.
▾
Cowork starts here
I have the concept clear now. I want to move to Cowork now, please prepare a CLAUDE.md file for me, and add any market research on separate files
  • Create a project
  • Do not add Instructions — you'll use the local CLAUDE.md file instead
  • Add the files you've downloaded from Chat (remember to extract the .zip file first, if needed)
Why this matters: without CLAUDE.md, every new session starts from zero and re-asks questions you've already answered.
6
Build the Financial Plan
What you'll learn: generating a real spreadsheet with stated assumptions and a live data table.
▾
Cowork
Help me build the financial plan. Build me a spreadsheet with startup costs, monthly operating costs, revenue assumptions, and a break-even estimate. Show your assumptions clearly. Add a table to monitor updated Food prices from USDA Economic
7
Explore Branding References with Chrome
What you'll learn: using the Claude for Chrome extension to research and capture visual references live.
▾
Cowork
I need to come up with some visual branding ideias for my restaurant - please explore some similar restaurants website using Chrome so we can build a reference for our branding guideline. Take some screenshots and add to the folder.
8
Create Branding Guidelines + a pptx Skill
What you'll learn: locking a visual direction, turning it into a reusable skill, then finishing the spreadsheet inside Excel.
▾
Cowork
We need to build a branding guideline for our restaurant - help me come up with it

Once you agree on a direction:

create a a pptx skill for us to build the decks. Create a template deck for me so I can evaulate

Open Claude for Excel to keep editing inside the tool:

Create a tab to detail the kitchen equipment I need to buy.
Important: the Claude extension in Excel and PowerPoint does not see your whole project — only what's inside the open workbook. Keep that in mind when asking it to reference other files.

Add a recurring task to keep prices current:

add a recurring task to update food prices on a monthly basis
9
Build the Investor Pitch Deck
What you'll learn: generating a numbers-consistent deck, then turning it into an interactive website.
▾
Cowork
Now build a short investor pitch deck (6 to 8 slides) covering the opportunity, the concept, the target customer, the financial highlights, and the ask. Pull the numbers from the financial plan so everything is consistent.

Turn it into an interactive website:

I want to impress my investors - let's make a website page for this presentation. Use the same technology of this website https://www.igloo.inc/ you need to scroll down to see the content, but the idea is to be something modern with this effect and you uncover more information as you scroll down
10
Hand Off to Claude Code: Build the Reservations Site
What you'll learn: moving the same project into Claude Code and publishing a working site.
▾
Code
OK, I need to build a website to capture reservations for my restaurant. Include: a hero section with the restaurant name and tagline, a short story/concept section, a sample menu (5-8 items pulled from the concept), location and hours, and a reservation form that actually send emails to <your_email> Keep it simple, one page, no login, no backend After approval, let's publish it using Vercel

Replace <your_email> with your own address before sending the prompt. This is where the Cowork track ends and the Claude Code track picks up — same project, same context, no re-explaining.

What "done" looks like
  • A financial plan (.xlsx) with stated assumptions and a live USDA price table
  • A branding guidelines doc + a reusable pptx skill
  • An investor pitch deck (.pptx or interactive site), numbers-consistent with the financial plan
  • A published reservations website, live on Vercel

Troubleshooting

  • Something looks off — describe exactly what's wrong and what you expected instead; ask Cowork to redo just that piece, not the whole project.
  • Claude can't see what you're looking at — take a screenshot and paste it in (Cmd+V / Ctrl+V).
  • Excel/PowerPoint extension seems to be missing context — reminder: it only reads the open workbook, not your whole project folder.
  • Losing track across sessions — ask Cowork to summarize what it currently knows from CLAUDE.md and MEMORY.md before continuing.
